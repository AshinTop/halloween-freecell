# Haunted FreeCell — ハロウィンのフリーセルとランタン救出パズル

🕯️ 静かな屋敷では、キングがかぼちゃに変身。暗い4つの塔が、あなたの一手を待っています。**Haunted FreeCell** は52枚の本格的なフリーセルに、ドラッグ操作と3つの Lantern Rescue 終盤パズルを加えたゲームです。空きを作り、次のカードを見つけ、塔を灯しましょう。

## このゲームの楽しみ方

- **52枚のフリーセル**：8列、1枚ずつ置ける4つのフリーセル、4組の組札。複数枚移動の容量も判定します。
- マウスやタッチで1枚または正しい並びをドラッグ。カードを選んで移動先を押す操作も使え、無効なドロップでは盤面が変わりません。
- **解法を確認した3つの Lantern Rescue**、番号付きの Classic 配り、セッション内の Undo、合法な一手のヒント。
- 猫のジャック、魔女のクイーン、かぼちゃのキングを描いたオリジナルカードと、任意の合成効果音。
- **最後まで収められると証明できたときだけ自動整理**。途中停止と、ひとまとまりの Undo に対応します。

## 基本ルール

組札はスートごとに **A から K** へ積み上げます。場の列は数字を1つずつ下げ、赤と黒を交互に並べます。空列にはどのカードでも置けますが、フリーセルには1枚だけです。連続した並びを運べる枚数は `(空のフリーセル + 1) × 2^(使用できる空列数)`。移動先そのものが空列の場合、その列は作業用の空列に含めません。合法なら組札からカードを戻すこともできます。

Lantern Rescue の **The West Tower、The Moonlight Ball、The Last Candle** も同じルールです。3問すべてに完全な解法があります。表示される目標手数は挑戦の目安で、数学的な最短を主張するものではありません。

### 自動整理は、止めることも戻すことも可能

手動の移動が成功すると、盤面のコピーを使って、**残りの全カードが組札への合法な移動だけで完成するか**を確認します。一部分だけ動かせる場合は自動では始まりません。最後まで確かめられたら1枚ずつ収め、各カードを通常の1手として数えます。設定上は1枚あたり最大約130ミリ秒で、多い場合は全体が約4秒になるよう短くします。動きを減らす設定では飛ぶ演出を省きます。

**Stop** または **Esc** で現在の位置に停止します。**Undo** を1回押すと、自動整理全体の開始前の盤面と手数へ戻り、勝手に再開しません。再開したいときは **Finish automatically** を押します。読み込んだセーブが完成可能な場合も、このボタンが表示されます。通常の中盤の Undo は、その後の自動整理を無効にしません。配り直し、再開、ヘルプ、言語変更、リサイズ、非表示、ウィンドウから離れた場合は、進行中の整理を安全に止めます。

## 操作方法

| 操作 | 入力 |
| --- | --- |
| カードや正しい並びを移動 | ドラッグして離す、または選択後に移動先をクリック／タップ |
| 露出した1枚を組札へ試す | ダブルクリック／ダブルタップ |
| Undo／ヒント | **U**／**H** または画面ボタン |
| 自動整理の停止／ドラッグ取消 | **Esc**。整理中は Stop ボタンも表示 |
| 完成可能な終盤を再開 | **Finish automatically** |
| 長い列をスクロール | 矢印、ホイール、隙間や動かせないカード上のスワイプ。ドラッグ中は上下端でもスクロール |

## ちょっとしたコツ

フリーセルを1つ残すと、1枚を退避できるだけでなく、長い並びをまとめて運ぶ容量も増えます。キングを動かす前に、その下でクイーンが待っていないか見てみましょう。自動整理は列を考えて組み替える必要がなくなるまで待ちます。そこまでの工夫は、プレイヤー自身の楽しみです。

## 記録とチャレンジの共有

保存が許可されていれば、現在の配り、時間、ヒント数、設定、パズルの自己ベストをローカルに残します。Undo 履歴はそのページのセッションのみで、端末間の同期はありません。[配り番号12345](https://halloween-freecell.crazy3d.org/?deal=12345)や[救出問題1](https://halloween-freecell.crazy3d.org/?puzzle=1)を共有でき、puzzle の 2・3 で残りを開けます。共有は実際の結果を使い、コピーできないときは文字を表示します。

## よくある質問

### ヒントに従えば必ず勝てますか？

いいえ。現在可能な一手を示す機能で、全体の解法ではありません。3つの救出問題は解法を確認していますが、任意の Classic 配りに同じ保証はありません。

### 空列へなら、どんな束でも運べますか？

できません。数字が降順で赤黒交互の並びであり、移動を支える空きセルや空列の容量が必要です。

### Undo で時間や自己ベストも戻りますか？

戻りません。盤面と手数を復元し、対象が自動整理なら一括で戻します。経過時間、使ったヒント、獲得済みの自己ベストは消しません。

## ローカルで実行・サイトに埋め込む

リポジトリのルートで HTTP サーバーを起動します。

```sh
python3 -m http.server 4173
```

**http://localhost:4173/** を開いてください。ビルドや依存パッケージは不要です。`file://` では JavaScript モジュールを読み込めない場合があります。

Node で付属のチェックを実行します。

```sh
npm test
```

Node のチェックは、全52枚の保持、移動容量、組札からの戻し、パズル解法、ドラッグと端のスクロール、取消、完全な終盤証明、Stop、一括 Undo、動きの削減、古いコールバックの隔離を確認します。ブラウザーの操作確認と併せて使うものです。

```html
<iframe src="https://halloween-freecell.crazy3d.org/?embed=1"
  title="Haunted FreeCell"
  style="display:block;width:100%;height:654px;border:0"
  allow="fullscreen" allowfullscreen></iframe>
```

デスクトップの基準は **1160×654 CSS ピクセル**です。低い枠ではカード列の内部だけをスクロールし、フリーセル、組札、道具を使える状態に保ちます。矢印や端でのドラッグスクロールにより、カードを極端に小さくせず長い列へ届きます。

寸法、保存、フォーカス、権限は[埋め込みガイド](EMBEDDING.md)へ。親サイトのツールバーを除いた高さを iframe に割り当ててください。
